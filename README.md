# APA Connect

Application APA Connect avec backend FastAPI, frontend React et MongoDB.

## Lancement local

Backend : installer les dépendances Python, configurer les variables locales, puis lancer `uvicorn server:app --host 0.0.0.0 --port 8000 --reload` depuis le dossier `backend`.

Frontend : installer les dépendances JavaScript, définir l URL backend locale, puis lancer `npm start` depuis le dossier `frontend`.

## Points à vérifier

- inscription intervenant
- connexion intervenant
- connexion admin
- affichage des intervenants
- filtres patient
- demandes de rappel
- passage manuel free/premium depuis l admin
